# Ценники на A4

Статический браузерный инструмент для подготовки PDF-ценников 10 × 15 см к печати.

## Возможности

- перетаскивание любого количества PDF-файлов;
- изменение порядка ценников;
- два ценника на альбомном листе A4;
- последний нечётный ценник по центру отдельного листа;
- масштаб 106% по умолчанию;
- светлая рамка для резки;
- сохранение векторного содержимого исходных PDF;
- проверка, что каждый исходник — отдельный одностраничный вертикальный ценник;
- полностью локальная обработка в браузере, без загрузки файлов на сервер.

При печати готового PDF нужно выбрать масштаб 100%.
